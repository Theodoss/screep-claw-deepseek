## W47N22 RCL3 死鎖分析

W47N22 達成 RCL3 後，舊的 RCL2 creeps 全數死亡。spawn 有 130e，extensions 有 ~50e，
total energyAvailable = 180e。containers 有 4000e 但 spawn 無法直接使用。

bootstrap 試圖 spawn rcl1Harvester [WORK,CARRY,MOVE] = 200e → 失敗（180 < 200）。
沒有 harvester 就沒有能源回流 → spawn 永遠卡在 180e → **永久死鎖**。

## 本輪改動

### 修改：`manager.rcl1Bootstrap.js` — micro-body 回退

當 energyAvailable < 200（BASIC_BODY 成本）時，改產 [CARRY, MOVE] = 100e 的緊急取能兵。
這個 creep 透過 `role.rcl1Harvester` 既有的 `acquireLooseEnergy` 路徑，
直接從 source container withdraw 能源後送回 spawn，打破死鎖。

```diff
- trySpawn(spawn, 'rcl1Harvester', BASIC_BODY, sourceIds);
+ if (energyCapacity >= 200) {
+   trySpawn(spawn, 'rcl1Harvester', BASIC_BODY, sourceIds);
+ } else if (energyCapacity >= 100) {
+   trySpawn(spawn, 'rcl1Harvester', [CARRY, MOVE], sourceIds);
+ }
```

- role.rcl1Harvester 的 `acquireLooseEnergy()` 已支援 container withdraw → 不需改 role 邏輯
- 一旦 spawn 收到能量 → energyAvailable ≥ 200 → 自動升級為 [WORK,CARRY,MOVE]
- deploy + git push 完成
