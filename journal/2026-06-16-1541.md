## 診斷

### 問題 1：W48N25 source 0 座標永久 null
`fillMissing` 使用 `!== undefined` 檢查，但 Memory 中 source.x/y 是 `null`。`null !== undefined` 為 true，導致 `resolveSourceId` 永遠無法從 (29,23) 重新搜尋 source。
→ **改 `fillMissing` 為 `!= null`**，同時覆蓋 null 和 undefined。

### 問題 2：Builder-Hauler-Container 三角死鎖
`getSpawnRequests()` 中 remoteBuilder 的 spawn 條件要求 `haulers.length > 0`，但 hauler spawn 要求 container 存在，container 又需要 builder 來蓋 → W48N25/W48N26 卡死。
→ **移除 builder spawn 條件中的 `haulers.length > 0`**。有 miner + 有 container site 就該生 builder。

### 問題 3：Remote Builder 不蓋路
`role.remoteBuilder.js` 的 `getRemoteWork()` 只找 container 工地/repair，不碰 road。road 工地由 `planRemoteRoads` 放置後沒人蓋。
→ **在 container 工地之後、repair 之前加入 road 工地搜尋**。優先級：container site > road site > container repair。

### 附註：W49N26 暫停
W49N26 在 tick 71719225 偵測到 invader，status=danger, pauseUntil=71720847。remote builder/reserver 因防禦機制 retreat 回主房，這是正常行為。
