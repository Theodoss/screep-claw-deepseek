## 本輪決定：修復 paused remote 時 hauler 不卸貨

**改動**：`role.remoteHauler.js` — 當 remote paused 時，若 hauler 持有能量，先嘗試卸貨到主基地再 standby。

**改前**：
```js
if (remote.isRemotePaused(homeRoom, remoteRoom)) {
    remote.retreat(creep, homeRoom);
    return;
}
```

**改後**：
```js
if (remote.isRemotePaused(homeRoom, remoteRoom)) {
    if (creep.store.getUsedCapacity(RESOURCE_ENERGY) > 0) {
        deliver(creep);
        return;
    }
    remote.retreat(creep, homeRoom);
    return;
}
```

**理由**：
- W48N25/W48N26 入侵導致 remote paused 時，滿能量的 remoteHauler 直接被 retreat 回家
- 能量卡在 hauler 身上無法被 colony 使用（remoteHauler_W48N25_1 卡了 1050 energy）
- 修復後 hauler 會先卸貨到 spawn/extensions/controller container 再 standby
- 在家且找不到卸貨目標時（全滿），hauler 會 waitAtHome，無害循環

**預期效果**：
- 入侵期間 trapped energy 減少
- shortNetEnergyRate 略微改善（釋放卡住的能量）
