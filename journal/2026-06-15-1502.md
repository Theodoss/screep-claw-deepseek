## 本輪改動 — rcl2Hauler near-full 提前切換 delivering

### 問題
兩個 rcl2Hauler (285/300, 280/300) 帶著 93%+ 能量卻 working=false，
跑回 source container（只有 10 能量）試圖取貨 → 浪費一趟來回。
這情況發生在 source container 幾乎被挖空時 — hauler 取不到足夠能量填滿，
但 `freeCapacity≠0` 所以不切換 delivering，卡在邊界狀態。

### 改動
`role.rcl2Hauler.js` run()：加入 80% 閾值（與 remoteHauler 一致）：
```diff
- if (!creep.memory.working && freeCapacity === 0) {
-     creep.memory.working = true;
- }
+ if (!creep.memory.working &&
+     (freeCap === 0 || (used > 0 && freeCap / totalCap < 0.2))) {
+     creep.memory.working = true;
+ }
```

邏輯：滿度 ≥80% → 直接送貨，不再等填滿。

### 預期效果
- 兩隻 near-full hauler 立刻轉向送貨，不再跑空 container
- 節省 ~20-30 ticks 來回時間 per hauler
- 提高 spawn/extension 補給頻率

### 下輪驗收標準

- energyAvailable 回補速度微幅提升
