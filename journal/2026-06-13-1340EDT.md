## 軍事攻擊預備系統

Theodos 要求：RCL4 後自動暫停升級、補滿 extension、生大型攻擊 creep、備戰完成回報。

## 新增功能

### 1. 攻擊預備模式 (manager.economy.js)
- `isPreparingAttack(room)` — 檢查是否在攻擊預備中（RCL4+ 且未產滿 2 隻 attack creep）
- `startAttackPrep(room)` — 進入 prep mode，記錄開始時間
- `recordAttackCreepSpawned(room)` — 每成功 spawn 一隻 attack creep 計數
- 在 prep mode 中：`upgradeRate = 0`、`upgraderWorkTarget = 0`、強制 `recovery = false`
- 產滿 2 隻後自動標記 `completed`，恢復正常經濟

### 2. 大型攻擊 creep body (manager.rcl2ContainerEconomy.js)
- `buildAttackBody(energyCapacity)` — 專為進攻設計
  - ~6% TOUGH（前排扛傷）
  - ~47% ATTACK、47% MOVE 交替（最大化 DPS）
  - 800e cap → `[TOUGH×3, ATTACK×4, MOVE×4]` (580e)
  - 1300e cap → `[TOUGH×4, ATTACK×7, MOVE×7]` (960e)
  - 1800e cap → `[TOUGH×5, ATTACK×10, MOVE×10]` (1330e)

### 3. Spawn 優先級
- 攻擊預備 > 防禦（hostile guard）> 正常 spawn
- Prep mode 中只生 attack creep，**不生任何其他單位**（save energy）
- 能量不夠就等到夠為止

## 記憶體狀態
```js
Memory.rooms.W49N25.attackPrep = {
  startedAt: <tick>,
  spawnedCount: 0,        // 已產數量
  completed: false         // 產滿 2 隻後變 true
}
```

## 預期效果
- RCL4 後自動觸發軍事預備
- Console 輸出 `[military] attack preparation started at RCL 4`
- 每生一隻：`[military] attack creep spawned: 1/2`
- 備戰完成：`[military] ATTACK FORCE READY — 2 creeps built`
- 之後自動恢復正常 economy（upgrade 重新開始）
