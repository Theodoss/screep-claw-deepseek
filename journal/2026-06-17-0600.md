## 本輪診斷 — 消耗爆增

主因：W49N26 invader 切斷一個遠程能源線 + upgrade 超支。

1. **W49N26 invader**：遠程採集暫停，能源收入缺口。invader 自 tick 71731630 存在，
   remoteGuard 已部署但仍在作戰中（TTL 僅剩 253）。
2. **upgrade 超支**：`storedEnergy > 300K` → `upgradeMultiplier = 1.35`，
   在能量淨流出時仍以 1.35x 燃燒庫存升級。upgradeRate=59.38 佔總收入 113%。
3. **rcl2Hauler ×3 + builder ×1 全部在 tower 補給**，說明 tower 在大量消耗能量（修理/補血？）。

## 本輪決策 — 限制庫存下降時的 upgrade 加速

**改動**: `manager.economy.js` — 庫存下降時限制 upgradeMultiplier ≤ 1.0

```javascript
// When energy reserves are declining, limit upgrade acceleration.
if (shortFlow.netRate < 0) {
  upgradeMultiplier = Math.min(upgradeMultiplier, 1.0);
}
```

**理由**: 當 shortNetEnergyRate < 0（庫存在下降），multiplier 不應超過 1.0。
原本 storedEnergy 433K 時 multiplier=1.35，使 upgradeRate=59.38 超出實際收入，
每天燒掉 ~49K 庫存。限制後 upgradeRate 降至 ~43（收入減固定成本），
預期節省 ~16 energy/tick。

**影響**: controller 進度從 ~59/tick 降至 ~43/tick，約慢 27%。
但能阻止庫存繼續以 -30/tick 速度蒸發，net 應收斂至 ~-15/tick。
