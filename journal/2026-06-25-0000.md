## 問題：W47N22 upgrader 走向遠端 source container

W47N22（RCL2, 無 controller container）upgrader 卡在
`task=withdraw:upgrade-container, e=0/50`。

根因：`economy.getUpgradeContainers` 回傳 controller 半徑 6 格內**所有** container，
包括 source containers。W47N22 的 source container 若在 6 格內，
upgrader Priority 4 會嘗試走向遠處的 source container 而非用近處的 spawn/ext。

## 改動：RCL≤2 跳過 upgrade container priority

`role.upgrader.js` Priority 4：加入 `level >= 3` guard。
RCL1-2 房（無 dedicated controller container）跳過 upgrade container，
直接 fall through 到 spawn/ext → 避免走向遠端 source container。

```diff
- if (!economyState.recovery && upgradeContainers.length > 0) {
+ if (!economyState.recovery && creep.room.controller.level >= 3 && upgradeContainers.length > 0) {
```
