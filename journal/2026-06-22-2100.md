## 本輪決定：hauler 優先供給 controller container

**改動**：`role.rcl2Hauler.js` — 在 ext→tower 之間插入 controller container 低能量優先級。

**邏輯**：當 controller container 能量 <200 且有 upgrader 需求時，hauler 優先填 controller 再填 extension。原先 ext 排在 controller 前面，導致 energyAvailable 不到 100% 時 controller 永遠飢荒、upgrader 閒置。

**新優先序**：Spawn → Controller（<200e）→ Extension → Tower → Controller → Storage
