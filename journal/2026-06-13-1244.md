## 瓶頸分析

hauler 全滿找不到卸貨目標。唯一消耗能量的是 upgrader（9.22/tick）。

economy.update() 將升級預算設為 (可用能量) × 0.8，即保留 20% 安全邊際。

## 改動
**manager.economy.js — 動態升級乘數**

```diff
- ) * 0.8
+ const upgradeMultiplier =
+   room.energyAvailable >= room.energyCapacityAvailable ? 0.95 : 0.8;
+ ) * upgradeMultiplier
```

當 room 能量滿時，升級乘數從 0.8 → 0.95，釋放更多能量給 upgrader。
能量不滿時維持原 0.8 安全邊際。
