## 本輪改動 — 遠程礦工移除 CARRY（與 D003 保持一致）

### 問題
`buildRemoteMinerBody()` 在遠程礦工 body 裡包含了 CARRY 部件：
- 上層 [W5,C,M] = 600 cost
- 下層 [W3,C,M] = 400 cost

但遠程礦工站在 container 上採礦（role.remoteMiner.js 確保移動到 containerPos 後停留）。
無 CARRY 時 `harvest()` 能量直接掉在地上，同格 container 自動撿起 → CARRY 完全浪費。
這與 D003（本地礦工不需要 CARRY）原理相同。

### 改動
```diff
  // 上層: 1300 capacity
- [W5, C, M] = 600 cost
+ [W5, M] = 550 cost  (節省 50 energy)

  // 下層: 
- [W3, C, M] = 400 cost
+ [W3, M] = 350 cost  (節省 50 energy)
```

WORK 數量不變，MOVE 數量不變，只移除 CARRY。
採礦效率相同（5 WORK = 10/tick = source 再生率），body cost 減少 50。

### 預期效果
- 每隻 remote miner 節省 50 energy body cost → replacementRate 微降 → upgradeRate 微升
- 2 隻 remote miner × 50 = 100 energy / spawn 節省
- 不影響採礦吞吐量（WORK count 不變）
- 不改變任何 creep 行為
