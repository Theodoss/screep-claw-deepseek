## 發現的問題

### 🐛 2 個 upgraders 閒置（stuck at spawn-fallback）
- `rcl1Upgrader-71797017`: working=false, energy=0, task=withdraw:spawn-fallback, ttl=23
- `rcl1Upgrader-71798565`: working=false, energy=0, task=withdraw:spawn-fallback, ttl=1499
- 兩個 upgrader 都卡在 spawn-fallback 無法取到能量
- spawn 只有 300 energy，多個 creep 競爭，withdraw 失敗後直接 return
- 從不 fall-through 到 storage（76,897 energy 可用）

### 根本原因
`role.rcl1Upgrader.js` 中 `spawn-fallback` 區塊在 `withdraw()` 失敗後（ERR_NOT_ENOUGH_ENERGY）直接 return，
沒有 fall-through 到 storage。造成 upgrader 在 spawn/ext 沒能量時卡死。

## 本輪優化

**修復 `role.rcl1Upgrader.js` spawn-fallback 不 fall-through 的 bug**

```javascript
// BEFORE: 無論成功失敗都 return
if (spawnExt) {
  creep.withdraw(spawnExt, RESOURCE_ENERGY);
  if (result === ERR_NOT_IN_RANGE) creep.moveTo(...);
  return;  // ← 失敗時也 return，block 了 storage fallback
}

// AFTER: withdraw 失敗時 fall through 到 storage
if (spawnExt) {
  creep.withdraw(spawnExt, RESOURCE_ENERGY);
  if (result === ERR_NOT_IN_RANGE) { creep.moveTo(...); return; }
  if (result === OK || result === ERR_FULL) { return; }
  // ERR_NOT_ENOUGH_ENERGY: fall through to storage below
}
```
