## 改動

### 新增：自動放置 extension 建築工地
**理由**: Controller 90.4%，RCL3 即將來臨（解鎖 +5 extensions，550→800 容量）。
目前 code 只有自動放置 container，沒有 extension 放置邏輯。
若不新增，RCL3 後將白白浪費擴展容量。

**改動**: `manager.rcl2ContainerEconomy.js`
- 新增 `placeExtensionSites(room, roomMemory)` 函數
  - 每 100 ticks 檢查（offset 73，與 controller container 的 37 錯開）
  - 計算 RCL 對應最大 extension 數量（透過 `CONTROLLER_STRUCTURES`）
  - 比對現有 extension + construction sites，補不足
  - 以 spawn 為中心、由內向外螺旋放置（range 1→5）
  - 避開牆壁、既有建築、既有工地
- RCL2 時 maxExtensions=5，RCL3 時=10 → 自動追加 5 座

**預期連鎖效應**:
1. RCL3 觸發 → `placeExtensionSites` 在 100 ticks 內放置 5 座 extension 工地
2. `support.runPriorityWork()` 偵測到 construction sites → 觸發 builder spawn
3. Builder 開始建造 extensions
4. Extensions 完成後 energy 總容量從 550→800
5. `buildWorkerBody(800)` → 7x WORK upgrader（升級速度再提升）
