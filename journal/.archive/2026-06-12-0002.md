## 本輪改動

**只改一個檔案**: `role.rcl2Hauler.js`

在 `findEnergyTarget()` 中，檢查完 spawn/extensions/towers 後，若全部已滿，則**直接餵食需要能量的 upgrader 或 builder**：

```javascript
// Feed support creeps (upgrader/builder) directly when structures are full
const needySupport = creep.room.find(FIND_MY_CREEPS, {
  filter: c =>
    (c.memory.role === 'rcl1Upgrader' || c.memory.role === 'rcl1Builder') &&
    c.store.getFreeCapacity(RESOURCE_ENERGY) > 0
});
if (needySupport.length > 0) {
  return creep.pos.findClosestByPath(needySupport);
}
```

**運作流程**: Miner → fills container b → Hauler 搬運 → 先餵飽 spawn/extensions → 若全滿 → 直接餵 upgrader/builder → upgrader 有能量升級 controller → builder 有能量建造 container c。
