# Screeps Journal - 2026-06-13 04:20 UTC

## 本輪重點：修正方向，收緊改動範圍

經 Theodos 指正後，修正兩個改動使其符合原有設計意圖。

## 殖民狀態（同前）
- 7 creeps, RCL3, energyAvailable 600/600, income 9/tick
- rcl1Upgrader 卡住：energy=0, task=null（無 controller container）

## 改動（推送至 claw-deepseek）

### 1. Upgrader fallback 收緊
- **舊**: 無 controller container 時全面挖 source（違反 static upgrader 設計）
- **新**: 只在 `controllerEmergency()` (ticksToDowngrade < 4000) 時才允許挖 source
- 平常無 controller container 時保持 idle，由 harvester/builder 做保底升級

### 2. Spawn fallthrough 收緊
- **舊**: miner/hauler spawn 失敗後繼續往下執行 builder/upgrader 邏輯
- **新**: spawn 失敗後只降級生成 1 隻 emergency harvester 然後 return
- 用 `spawnBlocked` flag，不破壞原有優先級

### 部署規則
- **只推 claw-deepseek**，絕不碰 sim
- `.env` SCREEPS_BRANCH 保持 `claw-deepseek`

## 預期效果
- Upgrader 正常情況下等待 controller container（不搶 harvester 站位）
- Controller 快降級時才啟動 fallback harvest
- Spawn 能量不足時最少保證 1 隻 harvester 存活
