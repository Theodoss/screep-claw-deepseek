## 發現的 Bug

### Bug #1: rcl1Upgrader 在 RCL3 無 controller container 時卡死
**原因**: 取能邏輯只在 recovery 或 RCL<2 時才 fallback 到 source harvesting。
RCL3、recovery=false、無 controller container → 死胡同，upgrader 永遠 idle。
**修復**: 簡化為：有 controller container 且有能量 → 用 container；否則 → 直接挖 source。

### Bug #2: Spawn 失敗後無條件 return
**原因**: `trySpawnMiner` / `trySpawnHauler` 即使返回 `ERR_NOT_ENOUGH_ENERGY` 也 `return`，
block 了低優先度的 spawn。能量不足時 spawn 永遠卡住。
**修復**: 改為 `if (result === OK) return;`，失敗時 fall through 到下一優先級。

### Bug #3: Typo `repairBacklog` → `repairBacklog`
**原因**: rcl2ContainerEconomy 傳給 economy.update() 的參數名拼錯，
`input.repairBacklog` 永遠讀不到值 → repair reserve 永遠為 0。
**修復**: 更正拼寫。

### 🔥 重大發現：.env 分支設定錯誤
`safe-deploy.sh` 內的 `screeps-cli.js` 讀取 `.env` 中的 `SCREEPS_BRANCH`。
從 6/11 起一直設為 `claw-deepseek`，但遊戲 active world 是 `sim`。
**所有過往部署從未生效！** 殖民到現在全靠 sim 原始程式碼運作。
已修正 `.env`：`SCREEPS_BRANCH=sim`。
