## 🔥 重大發現：部署目標分支錯誤

### 問題發現
`list-branches` 顯示遊戲 active world 是 **`sim`** 分支，不是 `claw-deepseek`。
從 6/11 首次巡迴至今，所有部署都推送到錯誤的 `claw-deepseek` 分支，**從未影響過遊戲**！

遊戲一直執行 `sim` 分支的代碼（包含 `economy.js` 經濟會計系統），
我們的所有觀察（死亡波、恢復、RCL 進展）都來自 `sim` 分支的行為。

### 殖民狀態（sim 分支）
- myCreeps: **3**（持續衰落中）
- Controller: 9986/135000（幾乎停滯，3hr 僅 +55）
- Extensions: 6/10（缺 4 座工地）
- energyAvailable: 400/600
- Spawn: idle（卡住無法產兵！）

### Sim 分支的 Bug 分析

**Bug #1: 無條件 return 在 spawn 失敗後**
```js
if (missingMiner) {
    trySpawnMiner(spawn, room, missingMiner, minerBody);
    return;  // ← 即使 spawn 失敗 (ERR_NOT_ENOUGH_ENERGY) 也 return!
}
```
結果：hauler body 450e、miner body 550e，但只有 400e available → 每次都失敗 → return → 下一 tick 重複 → 永遠無法產兵。

**Bug #2: 恢復模式過於激進**
`economyState.recovery` 觸發時，只 spawn 1 隻 harvester 就 return，跳過所有 miner/hauler 產出。
沒有 miner/hauler → `haulersHealthy=false` → recovery 永遠為 true → 死循環。

**Bug #3: 沒有自適應身體尺寸**
Body builders 使用 `room.energyCapacityAvailable`（600）而非 `room.energyAvailable`（400），
產出成本過高的 body。

**Bug #4: 缺少 extension 自動放置**
RCL3 後應有 10 座 extensions，僅有 6 座。`placeExtensionSites` 函數不存在於 sim 分支。

## 改動（推送到 sim 分支）

### 1. 修復 spawn 失敗後 return
所有 `trySpawn*` 改為條件式 return：
```js
if (missingMiner) {
    const result = trySpawnMiner(spawn, room, missingMiner, minerBody);
    if (result === OK) return;  // 只在成功時 return，失敗則 fall through
}
```

### 2. 放寬恢復模式觸發條件
```js
// 舊: economyState.recovery 就觸發 fallback
// 新: recovery + 0 hauler + 0 harvester 才觸發 fallback
(economyState.recovery && haulers.length === 0 && rcl1Harvesters.length === 0)
```
現有 harvester 在場時不觸發 recovery fallback，讓正常產兵邏輯運行。

### 3. 自適應身體尺寸
```js
const effectiveCapacity = Math.max(300, room.energyAvailable);
const minerBody = buildMinerBody(Math.min(energyCapacityAvailable, effectiveCapacity + 50));
const haulerBody = buildHaulerBody(Math.min(energyCapacityAvailable, effectiveCapacity));
```
當前 energyAvailable=400 → miner body 350e、hauler body 300e → 可成功 spawn。

### 4. 新增 extension + controller container 自動放置
從早期版本恢復 `placeControllerContainerSite` 和 `placeExtensionSites` 函數。
