## 本輪改動 — Bootstrap 能量閾值：<50% 時跳過支援 spawn

### 改動
`manager.rcl1Bootstrap.js` run()：在 `maintainSupport` 檢查後加入能量閾值：
```js
if (room.energyAvailable < room.energyCapacityAvailable * 0.5) {
    return false;
}
```

這在 builder/upgrader spawn 之前執行，只要 extensions 低於 50% 就跳過本次支援 spawn。
等 haulers 把 extensions 填回 >50% (=650 energy) 後才 spawn → 至少產出
[WORK×4, CARRY×2, MOVE×3] (cap=100) 而非 [W,C,M] (cap=50)。
