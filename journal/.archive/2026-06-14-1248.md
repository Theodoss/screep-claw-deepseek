## 本輪改動：Upgrader 在能量充裕時無視 recovery

**檔案**: `role.rcl1Upgrader.js`

**改動**: 新增 `ampleEnergy` 檢查（storedEnergy > 5000），當 energy 充裕時 `effectiveRecovery = false`，upgrader 照常升級而非做 recovery work。

```diff
+ const ampleEnergy = (economyState.storedEnergy || 0) > 5000;
+ const effectiveRecovery = economyState.recovery && !ampleEnergy;

- if (economyState.recovery) {
+ if (effectiveRecovery) {
    support.runRecoveryWork(creep);
  } else {
    support.runUpgraderWork(creep);
  }
```

**理由**:
1. storedEnergy=8450 遠超過安全線 5000，即使 recovery 中也不該停 upgrade
2. 只影響 upgrader 角色，不更動 economy/spawn 邏輯，風險極低
3. hauler replacement 正在 spawn 中，recovery 是暫時的；此改動確保過渡期不浪費升級進度
