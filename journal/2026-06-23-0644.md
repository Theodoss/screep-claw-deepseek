## 根因分析

### 核心 bug：upgrader role key mismatch
- `manager.population.js:430` 用 `rcl1Upgrader` 作為 plan roles key
- `manager.rcl1Bootstrap.js:205-207` 呼叫 `getRole(populationPlan, 'upgrader')`
- `getRole('upgrader')` 回傳 `{target: 0, limit: 0}`（plan 裡沒有 'upgrader' key）
- spawn 條件 `(count - dying) < limit` → `2 < 0` → **永遠 false**
- **永遠不 spawn 新 upgrader，死一隻少一隻**

這就是為什麼 06:00 的大 body 改動沒生效：新 upgrader 根本 spawn 不出來。

### 影響
1. upgrader 從 3→2，且不會補產
2. upgradeRate 下跌 24%
3. storedEnergy 開始淨流失（-5.75/tick short，-2.87/tick long）
4. 殖民地每 1000 ticks 淨損 4,286 能量

## 本輪改動

**`manager.population.js:430`**：`rcl1Upgrader` → `upgrader`

一行改動。plan roles key 與 bootstrap/getRole/stats 全部對齊。
