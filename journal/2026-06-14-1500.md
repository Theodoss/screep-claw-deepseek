**檔案**: `manager.economy.js`

**改動**: 固定 safetyReserve → 動態 safetyReserve：

```js
// Before (12:47 patrol):
const safetyReserve = incomeRate > 0
  ? Math.max(1, incomeRate * 0.1)
  : 0;

// After (本輪):
const safetyReserve = incomeRate > 0
  ? (storedEnergy > 5000 ? 0 : storedEnergy > 2000 ? Math.max(0.5, incomeRate * 0.05) : Math.max(1, incomeRate * 0.1))
  : 0;
```

**理由**:
1. 12:47 patrol 加了動態乘數但保留了固定 safetyReserve（10% 收入）
2. storedEnergy 34,487 時，safetyReserve 2.0/tick 過度保守
3. 動態 safetyReserve 與動態乘數互補：能量越高，兩個維度都越激進
4. storedEnergy ≤ 2000 時回退保守（10%），≤ 5000 時中等（5%），> 5000 時完全釋出
